## Scope boundaries

Deferred frontend rendering: every screen, timer display, offline UI, visual dashboards, rich-text editor UI, keyboard/contrast verification and design. Backend data/state/error contracts remain in scope. apps/web contains documentation only. No React/Vite/CSS/HTML/Tailwind/library implementation exists.

Future/excluded: payments, OCR, handwritten responses, negative marking, calls/TA role, webcam/biometrics, public student profiles, social feeds, comments, ratings, reactions/followers, push/email. Private query clarification is implemented and is not a public comment.

Those independent remaining items are explicitly disclosed rather than described as external blockers. No target is marked passed without evidence.
